description Descripción del Puesto

Buscamos un Analista de Sistemas Senior apasionado por la tecnología para unirse a nuestro equipo de desarrollo. Serás responsable de analizar, diseñar y supervisar la implementación de soluciones de software complejas que impactan a miles de usuarios.

Trabajarás en un entorno ágil, colaborando estrechamente con ingenieros de datos y arquitectos de soluciones para garantizar la escalabilidad y eficiencia de nuestros sistemas core.
